# TRG Prime 3.695.0: the Pillars of Faith audit's core fixes

16 November 2026. These are the core findings of the Pillars of Faith automation audit (module 0.12). Graham asked for them on 16 November ("move onto the core fixes"). Pillars of Faith 0.12.3 requires this release.

## CD10: Invested items' conditionals wait for Invest Item

- **Ruling (U4, 16 Nov).** "Invested-trait items' benefits wait for Invest Item."
- **Before.** An item's declared conditionals applied as soon as it was equipped (`equipmentInUse` → `wornAndStanding`). `wondrousActive` and `investedRefusal` already required investment for an item's wondrous effects and activations, so only the conditionals slipped through.
- **Now.** An item with the Invested trait offers its conditionals only while invested, as well as equipped. Items without the trait are unchanged.
  - Core items affected: Animal Staff, Staff of Imagery, Verdant Staff, Versarians Sight, Staff of the Coast Runner.
  - Every Invested-trait item a module ships is affected too, for example Pillars of Faith's Ancestor's Locket and Boneglass Monocle.

## CD13: Remove Disease and Remove Curse reach afflictions, and Mummy Rot is cured in order

- **Before.**
  - Remove Disease ("You attempt to counteract one disease afflicting the target") carried no row at all, so it did nothing on the sheet.
  - Remove Curse reached curse **effects** only, never a curse affliction.
- **Now.**
  - Remove Disease counteracts one disease affliction (`counteractAffliction`, disease).
  - Remove Curse first looks for a curse affliction. If it finds none, it says nothing and its curse-effect row runs as before. If it finds one, the effect row stands down: "one curse".
- **Removing Mummy Rot** (Fiends & Fables, ruled 16 Nov). The rule: Remove Curse first, then Remove Disease, and "a caster will not know if their attempts … have been successful until both castings have completed".
  - **Declaring the order.** An affliction declares it with `flags.trg-prime.cureSequence: ["curse", "disease"]`. Fiends & Fables' copy, which declares nothing, is recognised by its name.
  - **Each step.** Each counteract records its step on the affliction (`flags.trg-prime.cureSteps`) and whispers the true result to the GM. The caster's card says only that the step was attempted.
  - **The last step.** Remove Disease ends the affliction only if it succeeds after a successful Remove Curse. Either way it closes the attempt, so a failed cure starts again from Remove Curse.

## CD0: no pack writes the bare speed node

- **The fix.** Twenty-eight Active Effect changes wrote `system.combat.movement.<mode>` instead of `.base`. They were in the races (all eight), companions, familiars and feats packs (Swift Stride, Fleet Footed). They are re-keyed by `migrateMovementEffectKeys`' own rule; mode and value are unchanged.
- **Why it mattered.**
  - A character built from a core race after the world migration had run carried the bare key. Any later Speed bonus then threw "Cannot create property 'other' on number …" and stopped the actor's preparation.
  - This was confirmed live on 16 November with a Human and Bone Stride.

## CD14: a declared spell-attack bonus, and item casts that opt in

- **The problem.** Pillars of Faith's Eternal Resonance gives "+1-racial bonus to attack rolls and Save DCs generated by innate spells", ruled (U7) to cover every innate spell. The Save DC half had `spellDCBonus` with `innateOnly`. The attack half had no channel. A module casting option never reaches an innate cast, which shows no Casting Conditions prompt (found live on 16 November).
- **The new flag.** `flags.trg-prime.spellAttackBonus` mirrors `spellDCBonus`: `{ label, value, type, traits?, innateOnly? }`. Its rows join the spell attack's pool and stack there.
- **Item casts.** Both flags now accept `itemCasts: true`. Without it, an item's spell is skipped as before ("not your own spellcasting"). With it, the row reaches an item's spell too.
