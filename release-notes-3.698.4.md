# TRG Prime 3.698.4: version bump

18 November 2026. The same system as 3.698.3: no code, pack or migration changes. The version number is raised so that Foundry offers the update. That brings in everything since 3.698.1: the caster is always proficient with Flame Blade (3.698.2), and no Customise dialog for a conjured weapon plus Flame Blade's corrected card (3.698.3).

The world schema stays at 3.698.2, so a world already on 3.698.2 or later sees no migration. A world on 3.698.1 or earlier is offered one, which updates owned Flame Blade copies.
